# 미니 구조 통합 진행 현황

## 2026-11-18 1차: 기존 여행 조건·저장 보호

- 코스 시간 단축 시 원래 여행일·출발지·마감·선택 장소 보존.
- 일부 장소 확인 실패 시 확인된 장소만 진행할지 확인. 취소하면 선택과 조건 유지.
- 행사 기간에 맞춘 날짜 변경은 확인 후 적용.
- 북마크 쓰기 실패 알림 및 이전 정상 원본 백업. 손상 JSON/비배열을 빈 목록으로 덮어쓰는 동작 방지. 복구용 UI는 후속.
- 새 저장 코스에 schemaVersion 2와 장소 스냅샷 보존. 현재 카탈로그에 원본이 없으면 저장 당시 정보라는 표시와 함께 열람·텍스트 공유.
- 공유 비용을 보장된 상한으로 표현하지 않고 계획용 추정치로 표시.
- 전체 자동 검사 111건 통과, TypeScript 및 프로덕션 빌드 통과. 기존 데이터 삭제·DB 테이블 교체 없음.

## 아직 완료되지 않은 후속 작업

- 공통 여행일을 행사 탐색·지도까지 연결하고 뒤로가기 상태 복원 검증.
- 실제 행사 회차·휴무·취소 모델 및 알려진 제한과 미확인 상태 분리.
- 비용 확실성 모델과 출처별 수집/검수시각 분리(이번에는 오해 가능한 표현만 보정).
- 영문 별칭 검색·다국어 원문 병기.
- 손상 데이터 사용자 복구·내보내기 UI 및 구버전 코스 스냅샷 마이그레이션.
- 지도 동일 좌표 묶음, 현장 주소 카드, 체류시간 편집.
- 읽기 전용 코스 공유, 계정 북마크 병합, 오프라인 코스 읽기.

위 항목은 구현·검증 전이며 1차 검사 통과로 완료 취급하지 않는다. 독립 저장함 메뉴를 재도입하지 않고 코스 내부에서 장소/코스를 관리한다.
