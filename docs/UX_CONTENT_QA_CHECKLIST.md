# NOWRO AX·UX 콘텐츠 검수 체크리스트

검수 기준일: 2026-10-18

- [x] 영어 기본 언어 확인
- [x] 한국인과 외국인 모두를 설명하는 첫 화면 문구 확인
- [x] 대표 행동을 `Build my route` / `내 코스 만들기`로 명확화
- [x] 비회원 진입 문구를 `Start without an account` / `가입 없이 둘러보기`로 변경
- [x] 스탬프 메뉴를 `Stamps & rewards` / `스탬프·보상`으로 명확화
- [x] 개발자 표현을 `Preview content` / `미리보기 콘텐츠`로 정리
- [x] 샘플·미검증 장소 상태 표시 확인
- [x] AI 이미지를 실제 업체 사진과 구분하는 문구 확인
- [x] 부산 16개 구·군 선택 가능 확인
- [x] 모바일 하단 메뉴 글자 크기와 터치 영역 보정
- [x] 공개 외부 주소에서 보정 결과 확인

## 2. AX 검수

AX는 사용자가 시스템의 상태와 다음 행동을 이해할 수 있는지를 확인한다.

- [x] 현재 언어와 지역이 화면에 표시됨
- [x] 샘플·미검증 콘텐츠가 실제 제휴 장소로 오인되지 않도록 표시됨
- [x] 위치 권한 실패 시 지역 직접 선택 경로가 있음
- [x] 로그인 없이 둘러볼 수 있음
- [x] 스탬프·보상 메뉴의 목적이 메뉴명에 드러남
- [ ] 실제 업체 등록 후 주소·영업시간·가격·예약 상태를 상세페이지에서 검증
- [ ] 실제 결제 후 현장 QR 스캔 흐름을 운영 환경에서 검증
- [ ] 보상 배송·할인권 사용 상태를 운영 데이터로 검증

## 3. UX 검수

UX는 사용자가 원하는 정보를 빠르게 찾고 실수 없이 행동할 수 있는지를 확인한다.

- [x] 첫 화면에 검색, 지역, 시간, 예산, 관심사 입력이 있음
- [x] 대표 CTA가 하나의 행동으로 정리됨
- [x] 16개 구·군을 직접 선택 가능
- [x] 모바일 하단 주요 메뉴의 최소 터치 높이와 가독성 확인
- [x] 공개 콘텐츠와 운영 준비 콘텐츠를 구분함
- [ ] 장소 상세 화면에 영업시간·가격 기준일·주소·예약 필요 여부 추가
- [ ] 장소별 공유 URL과 검색 엔진용 제목·설명 추가
- [ ] 할인권·굿즈 연결 후 비활성 버튼을 실제 구매/등록 행동으로 교체
- [ ] 실제 사용자 5명 이상으로 외국인 모바일 사용성 테스트

## 4. 출시 전 차단 항목

- [ ] 샘플 장소를 실제 장소로 오인할 수 있는 표현 제거
- [ ] 실제 업체 사진 사용권 및 주소 검증
- [ ] Supabase 운영 DB·이미지 저장소·RLS 전환
- [ ] 개인정보 보관·삭제·탈퇴 정책 확정
- [ ] 결제·환불·QR 재사용 방지 운영 검증
- [ ] 고정 HTTPS 호스팅과 도메인 연결
- [ ] Android 실기기 테스트 후 Play 배포

현재 사이트는 기능 검수용 공개 미리보기 단계이며, 샘플·미검증 콘텐츠는 현장 사용 대상이 아니다.
