# 부산 전시 목록 API 개별 검수 — 2026-11-08

## 공식 규격

출처: https://www.data.go.kr/data/15063737/openapi.do

요청 주소: `https://apis.data.go.kr/6260000/BusanCultureExhibitService/getBusanCultureExhibit`

공식 요청 변수는 `ServiceKey`, `pageNo`, `numOfRows`다. 표준 문서에는 `resultType` 요청 변수가 명시돼 있지 않다. 제공 형식은 JSON+XML이다. 서비스키 값은 이 문서와 소스에 기록하지 않는다.

## 실조회 대조 결과

| 요청 | 결과 | 시간 |
|---|---|---|
| 공식 변수만 사용한 전시 조회(1페이지 10건) | HTTP 504 / XML 오류코드 05 / SERVICETIMEOUT_ERROR | 약 30.2초 |
| 전시 조회에 resultType=json 추가 | 로컬 요청 제한시간 초과 | 25초 |
| 전시 조회에 인증키 누락(대조군) | HTTP 401 / 코드 20 / SERVICE_KEY_IS_NULL | 약 0.14초 |
| 동일 인증키로 부산 축제 조회(대조군) | HTTP 200 / JSON 자료 반환 | 약 0.21초 |

전시 조회는 문서에 정의된 서비스 시간 초과 오류를 실제 반환했다. API 게이트웨이에 전혀 접속하지 못하는 상황이나 단순 0건 응답과 구분된다. 동일 키로 다른 서비스는 응답하지만 이것만으로 전시 서비스의 개별 승인·유효기간 상태까지 확인한 것은 아니다. 기관 전체 장애 또는 영구적인 서비스 중단으로 단정하지 않는다.

## 앱 코드 보정

- 전시만 별도 처리하는 `server/exhibitions.mjs` 분리.
- 공식 요청 변수 3개만 전송. 일반 관광 API의 응답 형식 지정 방식을 전시에 강제하지 않음.
- XML 및 JSON의 목록/단일 항목/정상 빈 목록 지원.
- 실제 오류코드 05, 인증/권한/호출제한 오류와 비정상 응답 형식을 구분.
- DOCTYPE/외부 엔티티 입력 거부. 누락·잘못된 응답을 정상 빈 목록으로 표시하지 않음.
- 응답에 키나 전체 요청 URL을 포함하지 않음.
- 운영 요청 제한시간 15초, 실패 캐시 60초 유지. 고객에게 제공처의 30초 오류 응답까지 기다리게 하지 않음.

실제 정상 전시 자료는 현재 제공처 시간 초과 때문에 검증하지 못했다. 정상 XML/JSON 처리는 공식 필드 기반 테스트 자료로 검증했다. 코드 보정이 제공처 응답 장애를 해결한 것으로 안내하지 않는다.

## 데이터 범위와 남은 조건

공식 목록의 제공 항목은 전시번호, 제목, 시작·종료일, 오픈런 여부, 시설명, 유무료 구분이다. 포스터 URL, 정확한 주소·좌표, 상세 금액은 명세에 없다. 시설명을 정확한 도로명주소나 공연장 좌표로 임의 변환하지 않으며, 별도 공식 상세자료 또는 검수된 시설 데이터로 보완해야 한다.

현재 장애 확인에는 오류코드 05와 위 대조 결과를 이용할 수 있다. 제공기관 문의나 활용신청 상태 확인은 이 검수에서 외부에 전송하지 않았다.
