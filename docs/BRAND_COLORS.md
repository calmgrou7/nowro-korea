# NOWRO 브랜드 컬러

메인 톤: **Ocean Charcoal + Fresh Lime**. 국내외 여행자가 직관적으로 읽을 수 있는 선명한 Travel Tech 화면을 지향합니다. 카키빛 중간색 대신 차가운 중립색을 기본으로 사용합니다.

| 역할        | 컬러           | 값        | 사용                                    |
| ----------- | -------------- | --------- | --------------------------------------- |
| 브랜드 기반 | Ocean Charcoal | `#20282B` | 주요 텍스트, 메인 히어로, Passport      |
| 주요 행동   | Fresh Lime     | `#BEF264` | 추천 시작, 저장, 활성 선택, 브랜드 표시 |
| 정보 강조   | Ocean Blue     | `#147D92` | 지도 기준점, 길찾기, 정보 링크, 포커스  |
| 기본 배경   | Cool White     | `#F6F8FA` | 페이지·입력 배경                        |
| 콘텐츠 표면 | Pure White     | `#FFFFFF` | 카드·쿠폰·입력 패널                     |
| 보조 텍스트 | Slate          | `#5E6B73` | 설명·가격 보조정보                      |
| 경계        | Mist           | `#DDE4E8` | 구분선·입력 테두리                      |

화이트·중립색 면적을 넓게 유지하고 차콜로 브랜드 무게를 줍니다. 라임은 핵심 행동과 선택에 집중합니다. 블루는 정보와 위치에 사용합니다. 전체 화면을 연두색으로 채우지 않습니다.

- 라임 버튼의 글자는 차콜로 표시합니다. 흰색 글자는 쓰지 않습니다.
- 차콜 히어로의 본문은 밝은 슬레이트, 제목은 흰색, 브랜드 포인트는 라임입니다.
- 선택 상태는 라임 틴트·테두리·아이콘/텍스트와 함께 표시합니다.
- 샘플·주의 고지는 따뜻한 별도 색으로 유지합니다. 브랜드 액션 색과 상태 색을 혼동하지 않도록 문구를 같이 표시합니다.
- 원본 여행 일러스트의 자연색은 허용하되 UI 면과 텍스트에는 컬러 토큰을 적용합니다.

소스의 중심은 `src/styles.css`의 CSS 변수입니다. 지도 마커·PWA theme-color·앱 아이콘에도 동일 팔레트를 적용합니다.
