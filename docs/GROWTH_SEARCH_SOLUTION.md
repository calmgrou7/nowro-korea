# NOWRO 유입 분석·네이버·해외·AI 검색 운영안

## 목표와 현재 상태

조회 수보다 **어느 채널의 어느 게시물이 장소 저장과 코스 생성으로 이어졌는지**를 판단한다.

GA4·검색 등록 계정은 아직 만들어지지 않았다. 이번 작업은 사이트의 연결 기능과 검색 기초를 준비하는 작업이다. 측정 ID가 없는 동안 Google로 기록을 보내지 않으며, 과거 방문을 나중에 소급 수집할 수 없다. 검색 등록·색인·상위 노출은 서로 다른 단계이며 등록만으로 노출을 보장하지 않는다.

## 1. 사이트에 준비한 기능

- 마스터 대시보드의 **방문 분석·검색 연결**: GA4 측정 ID, 활성화, 네이버·Google·Bing 소유 확인 코드 입력.
- **채널·게시물별 홍보 링크 만들기**: 같은 캠페인에서 채널과 게시물 번호를 구분하는 UTM 링크 생성·복사.
- 새로운 선택 동의 후에만 GA 태그 로드. 기존 동의는 새 외부 분석 동의로 간주하지 않는다. 이름·이메일·연락처·좌표·예산·예약·로그인 토큰을 이벤트로 보내지 않는다.
- 계정·저장 화면, 인증 링크, 관리자 접속은 측정 대상에서 제외. 동의 철회 시 전송 중지·GA 쿠키 정리·새로고침.
- 화면 이동은 수동 page_view로 한 번씩 기록한다. 실제 GA4 데이터 스트림의 향상된 측정은 꺼서 중복 페이지뷰와 자동 양식·검색어 수집을 방지해야 한다.
- 홈·지역가이드·코스·소개·공개 게시글의 주요 내용을 JavaScript 실행 전 HTML에도 제공. 검색로봇과 실제 방문자에게 같은 내용을 제공한다.
- 한국어·영어 주소(`?lang=ko`, `?lang=en`), 고유 제목·설명, canonical·hreflang, WebSite·Organization·공개 게시글 Article 구조화 데이터.
- `/sitemap.xml`은 공개 게시글을 자동 포함. `/feed.xml`은 공개 게시글 본문을 제공하며 초안은 제외한다.
- `/llms.txt`는 사이트 안내 보조 자료다. AI 노출 필수 파일이나 노출 보장 장치로 취급하지 않는다.

## 2. 계정 연결 순서 — 운영자 단계

### GA4
1. https://analytics.google.com/ 에서 NOWRO Korea 전용 계정·속성을 만들고 시간대는 대한민국으로 설정한다.
2. 웹 데이터 스트림에 https://nowrokorea.com 을 등록한다.
3. `G-`로 시작하는 측정 ID를 대시보드에 입력한다. **아직 활성화하지 않는다.**
4. 스트림의 **향상된 측정은 끈다.** 이 사이트는 수동 페이지뷰와 허용한 행동 이벤트만 보낸다. Google Signals·광고 개인 최적화도 사용하지 않는다.
5. 이벤트 데이터 보관 기간은 처음에는 2개월로 설정하고 Google 개인정보 안내·국외 처리 안내를 실제 운영정책에 맞춰 검토한다. 사이트 내부 분석 이벤트의 30일 보관과 GA4 보관은 별개다.
6. 대시보드에서 준비 확인 후 활성화한다. 여행객으로 접속해 선택 분석에 동의하고 실시간 보고서에서 확인한다. 관리자 본인 접속은 측정 대상에서 제외된다.
7. `generate_route`, `save_route`를 주요 이벤트로 설정한다. 같은 세션에서 여러 번 만들 수 있으므로 이벤트 횟수와 사용자를 구분한다.

기록은 GA4에 보관된다. 연결 ID 자체도 안정적으로 유지하려면 운영 서버 환경변수 `GA4_MEASUREMENT_ID`, `GA4_ENABLED=true`를 설정할 수 있다. DB에 저장된 명시적 설정이 환경변수 기본값보다 우선한다. 기존 운영 DB·이미지 영구 저장 연결은 별도 남은 작업이므로 재배포 후 설정을 확인해야 한다.

### 네이버
1. https://searchadvisor.naver.com/ 에서 `https://nowrokorea.com` 사이트를 추가한다.
2. HTML 메타태그 확인을 선택하고 `content="..."` 안의 값만 대시보드 네이버 확인 코드에 저장한다.
3. 네이버에서 소유 확인을 완료한 뒤 사이트맵 `https://nowrokorea.com/sitemap.xml`, RSS `https://nowrokorea.com/feed.xml`을 제출한다.
4. 홈·지역가이드·소개·공개 게시글 URL을 우선 확인한다. 수집·색인·노출 현황은 서로 나누어 점검한다.
5. 네이버 블로그 글에는 NOWRO의 관련 화면 링크를 넣고, `utm_source=naver_blog&utm_medium=referral`로 유입 이후 행동을 비교한다. 블로그 발행은 사이트 연결과 별도다.

### 해외 검색
1. https://search.google.com/search-console 에서 URL 접두어 속성 `https://nowrokorea.com/`을 추가한다. HTML 태그 방식이면 대시보드 Google 확인 코드로 연결할 수 있다.
2. 사이트맵을 제출하고 한국어·영어 대표 페이지를 URL 검사한다. 국가·검색어·페이지별 노출과 클릭을 확인한다.
3. https://www.bing.com/webmasters/ 에도 사이트와 사이트맵을 등록한다. 필요한 경우 대시보드 Bing 확인 코드를 사용한다.
4. 영문 안내에는 한국어 장소명·지도·공식 출처를 함께 유지한다. 미번역 상호·주소를 다른 업체의 영문 자료와 억지로 매칭하지 않는다.
5. 일본어·중문은 UI뿐 아니라 실제 관광 내용과 주소 번역을 완료한 다음 검색 언어를 확대한다. 현재 hreflang은 한국어·영어만 제공한다.

## 3. 채널·게시물 측정 규칙

| 항목 | 역할 | 예시 |
|---|---|---|
| utm_source | 어디에 게시했는가 | instagram / naver_blog / youtube / kakao |
| utm_medium | 매체 종류 | social / referral / email |
| utm_campaign | 하나의 홍보 주제 | busan-winter-2026 |
| utm_content | 게시물·소재 구분 | reel-001 / blog-002 / profile-link |

영문 소문자·숫자·하이픈·밑줄로 통일하고 개인정보를 넣지 않는다. **사이트 내부 메뉴 링크에는 UTM을 붙이지 않는다.** 외부 홍보용 링크만 구분한다.

예: `https://nowrokorea.com/?tab=ROUTES&utm_source=instagram&utm_medium=social&utm_campaign=busan-winter-2026&utm_content=reel-001`

| 행동 | 이벤트 | 해석 |
|---|---|---|
| 화면 방문 | page_view | 어디까지 들어왔는가 |
| 상세 보기 | view_item | 내용에 관심을 보였는가 |
| 장소 저장 / 취소 | save_place / remove_saved_place | 여행 후보로 남겼는가 |
| 코스 생성 성공 | generate_route | 코스 서비스 사용으로 이어졌는가 |
| 코스 저장 성공 | save_route | 코스를 실제로 보관했는가 |
| 상세 지도 링크 클릭 | map_click | 외부 지도 탐색으로 이어졌는가 |

지도 클릭은 실제 방문·예약·구매의 증거가 아니다. 광고·쿠폰·매출 전환은 아직 연결하지 않는다.

## 4. 첫 4주 운영

- 1주: 계정 연결·동의·이벤트·중복 측정을 검증한다. GA4 실시간과 실제 테스트 행동이 일치하는지 확인한다.
- 2주: 같은 주제를 2~3개 채널에 올리되 링크를 구분한다. 채널별 방문뿐 아니라 상세 보기·저장·코스 생성 비율을 비교한다.
- 3주: 반응이 좋은 주제의 제목·대표 사진·첫 문장을 한 요소씩 바꿔 비교한다. 특정 요일 행사와 전체 채널 효과를 혼동하지 않는다.
- 4주: 유지할 채널과 다음 달 콘텐츠를 정한다. 적은 표본은 효과가 확정됐다고 판단하지 않는다.

주간 표: 채널 / 게시물 / 캠페인 / 세션 / 상세 보기 사용자 / 장소 저장 사용자 / 코스 생성 사용자 / 코스 저장 사용자 / 메모.

예시 계산: 코스 생성 사용자 ÷ 해당 채널 유입 사용자. 단순 이벤트 횟수 ÷ 방문 수는 반복 클릭 때문에 왜곡될 수 있다. 분석에 동의하지 않은 방문자·차단 앱은 빠질 수 있고, 메신저·AI 앱은 출처를 전달하지 않을 수 있으므로 정확한 전체 방문 기록이라고 단정하지 않는다.

## 5. AI 검색용 콘텐츠 원칙

검색이 가능한 본문과 실제로 도움이 되는 답을 우선한다. 지역·장소·일정·지도·교통·공식 출처·확인일을 명확히 적고, 일정 미확인과 과거 회차를 구분한다. 실제 결제·영업·외국어 메뉴·예약 여부를 확인 없이 만들지 않는다. 정보가 바뀌면 기존 URL에서 수정하고 변경일을 남긴다.

추천 주제: 부산 반나절 여행을 어떻게 계획하나요 / 비 오는 날 부산에서 갈 곳 / 해운대와 광안리를 같은 코스로 묶을 수 있나요 / 외국인이 한국어 주소를 지도에 사용하는 법. 실제 자료가 확인된 답부터 작성한다. 가짜 리뷰·근거 없는 순위·자동 생성한 중복 문서는 만들지 않는다.

## 6. 다음 단계

- 영구 DB와 콘텐츠 보존을 완료한 뒤 관광지·행사별 영구 상세 URL을 확대한다.
- 공식 번역·주소·일정을 검증한 실제 콘텐츠에만 TouristAttraction·Restaurant·Event 등의 구조화 데이터를 추가한다. 현재 미확인 축제 자료를 Event로 부풀리지 않는다.
- 상세 페이지별 유입과 코스 이용을 연결하는 분석, 내부 운영자 제외·이벤트 중복·동의 철회 브라우저 검증을 실제 측정 ID 등록 후 실시한다.
- 통합 보고서 자동 수집은 GA4/Search Console API 권한이 생긴 다음 단계다. 현재 대시보드는 연결 설정과 링크 생성 기능이며 실제 통계 차트가 연결됐다는 뜻이 아니다.
