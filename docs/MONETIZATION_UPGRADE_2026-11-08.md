# NOWRO 수익화 업그레이드 — 1차 적용 범위

사용자가 제공한 `nowrokorea-monetization-plan.md`의 0~1단계 중 현재 운영 가능한 기반을 구현한다. 2026-11-08 기준 제휴 프로그램 가입·발급 링크는 **없음**으로 확인했다. 실제 수수료·매출·예약 수치나 유료 계약을 만들지 않는다.

## 이번 구현

- [x] 종료된 축제와 종료일 미확인 축제는 기본 목록에서 제외. 별도 토글로 지난·미확인 자료를 열 수 있다. 미확인 일정은 코스에 넣지 않는다.
- [x] 외국어 화면에 한국어 장문이 그대로 펼쳐지는 경우를 방지. 제공된 외국어 설명은 우선 사용하고 한국어만 있으면 원문 펼치기로 보관한다. 상호·주소는 지도 사용을 위해 원문을 유지한다.
- [x] `/ko/`, `/en/`, `/ja/`, `/zh-cn/`, `/zh-tw/` UI 언어 경로 지원. 기존 `?lang=` 링크도 지원한다. 검색 canonical·hreflang·사이트맵은 본문이 준비된 한국어·영어를 우선한다. 일본어·중문 본문 완역으로 표시하지 않는다.
- [x] 관리자 제휴 상품 등록: 제휴사, 상품 번호, 공개 HTTPS 링크, 한국어·영어 제목, 표시 최저가(선택), 통화, 사용 종료일, 노출 영역.
- [x] 카테고리·지역·키워드 규칙 또는 특정 장소를 통한 연결 후보 생성. 후보는 승인 대기이며 자동 노출되지 않는다.
- [x] 상품 검수와 장소 연결을 각각 승인해야 공개. 편집 시 이전 승인·연결이 무효화된다. 중지·기한 종료·장소 비공개/종료 시 노출하지 않는다.
- [x] 승인된 실제 상품만 상세페이지·코스 정류장·지역 숙소 영역·여행 준비 영역에 표시. 등록 상품이 없으면 해당 영역은 숨긴다.
- [x] 제휴·수수료 안내 5개 언어, 외부 링크 sponsored 표시. 제휴가 일반 코스 추천 점수나 예상 비용을 몰래 바꾸지 않는다.
- [x] 제휴사별 추가 추적 변수는 기본 비활성. 제휴사가 허용한 변수만 선택할 수 있고 기존 URL 값을 덮어쓰지 않는다. 예약·매출 확정은 별도 제휴사 보고서가 필요하다.
- [x] `click_affiliate`에 상품·제휴사·장소·언어·화면 구분을 전달할 준비. GA4는 이전과 동일하게 등록·활성화·새 선택 동의가 모두 있어야 전송한다. API 키·이메일·좌표·여행 예산을 분석으로 보내지 않는다.
- [x] `view_item`의 행사/장소 구분, `add_to_route`, `generate_route`, `save_route`, `save_place` 및 `share_route`. 기존 이벤트 이름을 중복 발생시키지 않는다.
- [x] 코스 내용 복사·텍스트 다운로드·이메일 앱·기기 공유. 메일 수신자 입력과 발송은 사용자가 직접 한다. 이메일 주소를 수집하거나 자동 발송한 것으로 표시하지 않는다.
- [x] 쿠폰이 없는 경우 빈 '코스 주변 혜택'을 숨김. 향후 파트너 쿠폰의 소유자·다국어 제목·할인·기간·위치·QR/PIN 유형·상태 구조 정의.

- [x] 공개 화면 검수 중 발견한 관광 API 지연 경합 보정: 계획용 정보 선택을 항상 제공하고, 관광공사 API 시간 초과 때 공식 부산 해양체험 자료를 보완한다. 서비스 자체가 정상화됐다고 표시하지 않는다. 일정 미확인 실데이터 행사는 추천 계산에서도 제외한다.

## 운영 순서

1. 마스터 관리자 → **제휴 상품·연결 승인**.
2. 실제 프로그램 가입·승인 후 발급된 공개 상품 링크만 입력한다. 제휴사 계정 비밀번호·API 비밀키는 넣지 않는다. 현재 허용된 제휴사 공식 도메인의 전체 URL을 사용한다. 다른 추적 도메인이 발급되면 먼저 공식 프로그램 문서와 도메인을 확인해야 한다.
3. 상품명·가격·언어·취소 조건과 목적지를 확인한다. 가격을 모르면 공란으로 둔다. 0원과 가격 미확인을 혼동하지 않는다.
4. 지역·카테고리·키워드 또는 특정 장소를 고르고 **상품 초안 저장**.
5. **규칙으로 연결 후보 생성**. 특정 장소를 고르면 그 장소가 규칙보다 우선한다.
6. 검수 확인 후 **상품 검수 승인**, 각 후보의 **이 장소 연결 승인**을 각각 실행한다. 여행 준비 상품은 특정 장소 없이 상품 승인을 통해 해당 영역에 노출된다.
7. 실제 화면에서 링크·표시 가격·광고 고지·언어를 확인한다. 공급 상품이 끝나면 **노출 중지**한다.

## 계정·계약·비용 때문에 아직 실행하지 않은 부분

- [ ] Render 무료 서비스의 절전 해제. 실제 서비스는 `free`로 확인했으며 유료 전환·결제·외부 유료 서비스 가입은 실행하지 않았다. 절전은 프론트 코드로 없앨 수 없으므로 유료 상시 운영 또는 정적 프론트/API 분리 배포를 선택해야 한다.
- [ ] 제휴 프로그램 가입·승인, 실제 상품 링크와 제휴사별 추적 변수 확인. 현재 실제 상품은 0건이며 고객에게 가짜 예약 버튼을 표시하지 않는다.
- [ ] GA4 실제 계정·측정 ID 연결과 실시간 수신 검증. 현재 분석 계정이 없는 상태라 데이터 수집은 꺼져 있다.
- [ ] 자동 이메일 발송 공급자·인증된 발신 주소 연결. 서비스 연결 전에는 이메일 입력·마케팅 연락처 수집을 하지 않는다. 향후 코스 발송 동의와 선택 마케팅 수신 동의를 분리한다.
- [ ] 파트너 월 구독·성과 정산·자동 청구·NOWRO Pass 결제·해외 결제·취소/환불 절차. 실제 요금과 계약이 정해지지 않아 활성화하지 않는다.
- [ ] 파트너 쿠폰 발행·사용 검증·CPA 과금. 기존 로컬 결제·스탬프 테스트와 운영 상품을 섞지 않는다.
- [ ] 영구 DB·이미지 저장소 연결. 현재 운영 DB는 재배포 시 데이터 보존을 별도 확인해야 한다. 상용 제휴 상품을 대량 등록하기 전에 이 작업을 완료해야 한다.
- [ ] 일본어·중문 관광 API 이용 승인 및 정확한 언어별 장소 연결. contentid가 언어 간 같다고 가정하지 않는다.
- [ ] 행사별 영구 상세 URL과 확인된 날짜·장소에만 Event/Restaurant/TouristAttraction 구조화 데이터를 적용. 미확인 축제를 현재 행사로 검색에 발행하지 않는다.
