# NOWRO 공통 디자인 적용

2026년 11월 13일 디자인 매뉴얼과 검토 시안의 기준을 기존 운영 코드에 연결했다. 별도 시안의 임시 저장·순서 예시는 가져오지 않고 기존 API·회원·권한·저장·계산을 유지한다.

## 변경

- 공통 토큰과 구성은 `src/design.css`에서 관리한다. 흰색 바탕, 옅은 회색 보조 영역, 차콜 본문, 행동·선택에 집중한 라임색을 사용한다.
- 외부 Google Fonts 요청을 제거하고 한글·영문 시스템 서체를 같은 계열로 사용한다.
- 헤더·글자·카드·필터·버튼·입력·모달·소개·관리 화면의 기본 모서리와 색상 기준을 통일한다.
- 홈에는 실제 행사·동네 검색창을 연결했다. 기존 행사 분류·지난 행사 필터·검색 로직을 유지한다. 긴 일정 안내는 접어서 펼친다.
- 공식 행사 카드는 데스크톱 3열·모바일 2열이다. 공식 포스터는 전체가 보이도록 contain을 사용한다. 사진 없음 대체 로고는 유지한다.
- 공식 상세 모달은 데스크톱에서 사진과 위치·기간·코스 선택을 나란히 표시한다. 모바일은 한 열로 표시한다. 저장 토글·주변 장소·지도·제휴는 유지한다.
- 코스는 담아둔 장소를 먼저 보여주고 시간·예산·이동수단을 펼쳐서 조정한다. 상세에서 코스 선택 또는 바로 코스 만들기로 들어오면 조건을 펼쳐준다. 보관한 코스는 접어서 볼 수 있다.
- 사용자 승인 메뉴인 홈·지역가이드·코스를 모바일 하단 3개 메뉴로 유지한다. 기존 저장 링크의 코스 이동도 유지한다.

## 검증

- 전체 검사 106건 통과. 최종 빌드 및 문법 검사 통과.
- 운영 계정과 분리된 메모리 DB와 실제 공개 행사 자료를 사용해 홈 검색, 행사 상세, 저장, 코스 선택, 추천 계산을 검수했다.
- 매직페스티벌을 검색하고 상세에서 저장·코스 선택 후 10시 출발 계획용 추천 결과를 수신했다. 결과는 기존과 동일하게 예상 운영시간·요금·이동 정보 안내를 유지한다.
- 390px·320px에서 문서 전체 가로 넘침 없음. 모바일 필터는 내부에서만 가로 스크롤한다.
- 검수 중 발견한 검색 아이콘과 확인 체크박스의 세로 배치를 가로 배치로 보정했다.
- 개별 행사의 실제 운영·가격·매일 개최 여부, 외부 인증 계정·예약·결제의 실거래를 검증했다는 의미는 아니다.

## 보존

검색·코스 요청은 기존 서버로 연결한다. 샘플 시안의 가짜 후기·가격·순서 계산을 운영 화면에 넣지 않는다. 원래의 `styles.css`와 새 공통 기준을 분리해 추적할 수 있게 했으며, 변경은 Git으로 되돌릴 수 있다. 회원·게시물·권한을 이 디자인 변경으로 삭제하지 않는다. 운영 DB 영구 보존 문제는 별도 연결 작업으로 남아 있다.
