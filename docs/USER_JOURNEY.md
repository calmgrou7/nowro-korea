# NOWRO 고객 이용 동선 — 2026-11-08

## 메뉴와 화면

| 메뉴 | 목적 | 다음 행동 |
|---|---|---|
| 홈 | 축제·공연·전시·체험 발견 | 상세 확인, 바로 코스 만들기 |
| 지역가이드 | 동네·관광지·맛집 탐색 | 지역 필터, 상세 확인 |
| 코스 | 선택 장소·여행 조건과 결과를 한 화면에서 관리 | 조건 입력 → 계산 → 상세 → 코스 저장 |
| 저장 | 저장한 장소와 저장한 코스를 구분 | 장소 선택 → 새 코스, 저장한 코스 다시 보기 |
| 나우로 소개 | 서비스·이용법·부산 여행·파트너 참여 안내 | 세 게시판과 최신 소식 |

상단은 다섯 메뉴, 모바일 하단은 홈·지역가이드·코스·저장의 네 메뉴를 동일한 이름과 목적지로 연결한다. 코스는 `?tab=ROUTES` 독립 화면이며 홈 내부로 스크롤시키지 않는다.

## 주요 경로

1. 홈/지역가이드 → 장소 상세 → 저장 → 저장한 장소 선택 → 코스 설정 → 추천 결과 → 상세 확인/코스 저장.
2. 홈 바로 코스 만들기 → 코스 설정 → 추천 결과 → 상세 확인/코스 저장.
3. 장소 상세 → 주변 음식점·카페·쇼핑 선택 → 현재 장소 포함 여부 확인 → 코스 설정.
4. 저장 → 저장한 코스 다시 확인 → 지도·공식 안내 → 방문.

상세의 코스 연결이 실패하면 상세 화면을 먼저 닫지 않는다. 홈/지역가이드의 분류·검색·더보기 상태를 유지하며 브라우저 뒤로가기에서는 해당 기록의 스크롤 위치를 복원한다. 여행 조건을 바꾸면 이전 추천 결과를 비워 재계산하도록 한다.

## 혜택 연결 자리

코스 결과 다음에 코스 주변 혜택 영역을 둔다. 현재 실혜택은 없으며 준비 중임을 명시한다. 임의 쿠폰·할인율이나 적용 금액을 만들지 않는다.

향후 데이터에는 장소 식별자, 쿠폰/할인행사 종류, 유효기간, 사용시간·요일, 최소 결제금액, 사용 방법, 활성/중지/소진/종료 상태, 광고·제휴 여부가 필요하다. 고객이 혜택 장소 추가·교체를 선택하면 추가 이동시간과 비용을 다시 계산한다. 사용 조건이 확인된 혜택만 할인 후 예상 비용에 반영한다.

## 정보와 저장 범위

장소 북마크는 현재 브라우저에 저장된다. 저장한 코스는 별도 계정/비회원 보관 안내를 따른다. 영구 저장소 접근이 해결되기 전에는 재배포 후 영구 보존을 보장하지 않는다. 운영시간·요금·방문 가능 여부는 추정치와 검증 사실을 구분하며, 예약이나 결제를 완료한 것으로 표시하지 않는다.

## 사용자 매뉴얼

나우로 소개 → NOWRO 이용가이드에 실제 메뉴 이름과 위 순서를 한국어·영어로 반영한다. 향후 혜택도 현재 이용 가능 기능과 구분해 설명한다.
