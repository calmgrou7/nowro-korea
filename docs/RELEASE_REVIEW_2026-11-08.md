## 외부 조건 때문에 미완료

1. **전시 자료 수신**: 부산 전시 API를 공식 주소·요청 변수로 재검증했으나 JSON/기본 응답 모두 시간 초과. 장애 안내·재시도·부산문화포털 링크는 구현. 자료를 임의 생성해 채우지 않음.
2. **영구 저장소·회원 저장 동기화**: 기존 Supabase `rpkvpbdzemesckzizybq`가 현재 연결된 두 계정의 프로젝트 목록에 없음. 따라서 운영 DB/Storage 이관과 재배포 후 데이터 영구 보존을 완료로 표시하지 않음. 브라우저 장소 저장은 해당 기기에만 보관.
3. **실제 영업/폐업 검증과 실제 이동시간**: 인허가·사업자 정보 매칭과 외부 교통 공급자 연결 필요. API 누락이나 장애를 폐업으로 처리하지 않으며 요금·운영·이동시간은 방문 전 확인 또는 계획용 추정치로 표시.
4. **업체·콘텐츠 실물 검수**: 실제 소유권, 사진 권리, 가격, 영업시간은 담당자/운영자 확인 필요. 코드 검사로 사실 검증을 대체할 수 없음.
