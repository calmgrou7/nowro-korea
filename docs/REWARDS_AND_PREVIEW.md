# 스탬프 보상 및 쇼핑 연결

## 현재 구현
- 부산 4개 지역에서 결제 확인된 스탬프를 각각 1개 이상 받으면 완주.
- 캠페인당 굿즈 배송 또는 할인 보상을 한 번 선택. 서버 트랜잭션과 고유 제약으로 중복 차단.
- 굿즈는 예시 카탈로그. 국내/해외 주소, 연락처, 수집 동의를 입력해 테스트 신청. 관리자만 주소 열람 및 준비/발송/배송 완료 처리. 발송 시 운송사와 운송장 필수.
- 할인은 신청/준비/사용 상태를 관리하는 프로토타입. 실질 할인율·가맹점·유효기간·정산은 운영 전에 확정해야 한다.
- 결제 참조번호와 금액을 입력하는 테스트 결제 확인은 로컬 운영자 미리보기에서만 제공. 실제 PG 승인 기능이 아니다.
- 결제 확인 → 유효기간 2분 서명 QR → 고객이 카메라로 QR URL 열기 → 서버 검증 후 자동 등록. 수동 코드 입력도 가능.
- 같은 결제는 한 번만 사용. QR 재발급은 이전 QR을 무효화. 사용 기록은 게스트 데이터 삭제 후에도 재사용 차단용으로 유지.
- 기존 결제 증명이 없는 스탬프는 완주 보상 계산에 포함하지 않음.
- 주소는 브라우저 저장소에 저장하지 않으며 감사 로그에서 제외. 테스트 배송 신청은 7일 게스트 세션 만료 시 삭제되므로 실 운영 배송 접수로 사용하면 안 됨.

## 쇼핑 메뉴
혜택·샵에 할인권 구매, 할인권 등록, 굿즈 구매 메뉴 추가. 아래 HTTPS 환경변수가 없으면 연결 준비 중으로 표시하고 구매 버튼을 비활성화한다.
`DISCOUNT_SHOP_URL`, `TICKET_REGISTER_URL`, `GOODS_SHOP_URL`.

## 실제 서비스 연결 시
로그인 사용자 식별, PG 서버 승인/서명된 웹훅 및 취소·환불 처리, 주문자와 결제의 연결, 재고·배송비·배송국가 정책, 할인권 실제 사용 검증, 운송사 연결이 필요하다. 로컬 운영자 역할 전환을 공개 서버에서 활성화하지 말 것.
기존 PostgreSQL 준비 스키마에는 이번 결제·배송 테이블/권한이 아직 반영되지 않았으므로 별도 마이그레이션과 권한 검증 후 연결한다.

## 임시 외부 미리보기
현재 URL: https://yield-verbal-manor-panel.trycloudflare.com/
Cloudflare Quick Tunnel을 통해 별도 8788 서버를 공개. `scripts/public-preview.mjs`는 `.data/public-preview` DB만 사용하며 운영자 역할 전환과 테스트 결제 API는 차단한다. 기존 로컬 등록/주문 DB와 분리된다.
PC와 서버/터널 프로세스가 실행 중일 때만 이용 가능. 재시작하면 주소가 바뀔 수 있다. 정식 호스팅이 아니다.
실행: `npm run build`, `node scripts/public-preview.mjs`, `.tools/cloudflared.exe tunnel --url http://127.0.0.1:8788 --no-autoupdate --protocol http2`.
