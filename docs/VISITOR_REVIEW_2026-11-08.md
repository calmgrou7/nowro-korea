# 관광객 관점 리포트 반영

사용자가 전달한 Claude 보고서를 현재 배포본과 대조했다. 기존에 승인한 홈 순서(소개 이미지 → 행사 탐색 → 코스 → 저장 → 게시판)는 유지한다.

## 이번 반영

- 흰 배경의 코스 진입 박스 제목·설명 대비를 명시적으로 지정.
- 768px 이상에서는 하단 내비게이션을 숨기고, 모바일에서는 4열 유지.
- 메인 공식 불꽃축제 사진을 자체 정적 파일로 저장. 사진 로드 실패 시 로고를 텍스트 위에 겹치지 않음.
- 해운대빛축제는 공식 축제 API의 야간 조명 사진으로 교체. 과거 회차 자료사진 표시.
- 실제 API 장소에도 무조건 표시되던 샘플 문구 수정. 이미지 없는 실재 장소에는 관련 없는 광안리 사진 대신 기존에 요청한 회색 로고 처리.
- 편집 행사에서 미확인 0원 가격은 숨기고, 업체가 0원으로 등록한 항목은 무료 표시.
- 관광정보 상세·주변 장소에 Google Maps / Naver Map / 주소 복사 공통 컴포넌트 적용.
- 첫 화면 상단 얼리 액세스 안내는 푸터로 이동. 위치·기간·영업정보 관련 중요한 불확실성은 숨기지 않음. 공식 API 출처를 현장 검증으로 과장하는 Verified 배지는 추가하지 않음.
- 탐색·저장·코스·게시판 등의 공통 방문자 UI에 일본어·간체·번체 표현 추가. 기존 이중 언어 인라인 문구 목록은 VISITOR_I18N_AUDIT.json에 기록.
- 공식 데이터 출처 링크를 API 실행 주소 대신 안내 페이지로 교체.
- 1200×630 공유용 대표 이미지 적용.

## 사진 출처

- 부산불꽃축제: 부산시 FestivalService, 원본 https://www.visitbusan.net/uploadImgs/files/cntnts/20241022165920388_ttiel
- 해운대빛축제: 부산시 FestivalService UC_SEQ 440, 원본 https://www.visitbusan.net/uploadImgs/files/cntnts/20221227165437336_ttiel
- 공식 데이터 안내: https://www.data.go.kr/data/15063500/openapi.do
- 2026-11-08 공식 API에서 확인. 리사이즈·WebP 변환, 공유 이미지는 문구 합성. 해당 연도 현장 촬영 사진이라고 표시하지 않음.

## 남은 단계 — 이번 완료로 간주하지 않음

- 모든 페이지·관리자·사용자 게시물의 5개 언어 완역. 공통 UI 외 긴 설명에는 영문 대체가 남아 있음.
- 일문·중문 관광 API 이용 승인·응답 검증 및 장소 단위 언어 연결. 언어별 contentid를 같다고 가정하거나 좌표만으로 업체를 병합하지 않음. 이번 환경에는 로컬 관광 API 키가 설정되어 있지 않음.
- 한글만 제공된 상호·주소의 공식 영문 자료 보완. 지도 열기와 원문 복사는 제공하지만 번역 완료로 표시하지 않음.
- 언어별 URL / hreflang, 실제 행사별 영구 상세 URL과 Event 구조화 데이터. 제공처 일정과 연결되는 검증이 우선.
- 외국어 메뉴·카드 결제·출구 번호·예약 여부는 제공처가 확인한 내용만 입력. AI 추정으로 실제 운영 사실을 만들지 않음.
- 첫 화면 전체를 다른 구조로 교체하는 제안과 임의 카테고리 사진 대체는 기존 사용자 결정과 충돌하므로 채택하지 않음.
- 지도 화면은 기존 목록/지도 전환을 유지하며, 저장 장소의 지도 통합은 별도 작업.

## 검증

- TypeScript 및 프로덕션 빌드.
- 기존 전체 회귀 검사 82건.
- 실제 배포 후 1440px / 390px 화면, 일본어 탐색 메뉴, 공식 이미지 로드 및 상세 지도 링크 확인.
- 변경 전후 화면은 로컬 docs/visitor-review에 저장.
