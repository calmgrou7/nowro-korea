# 부산 전체 구·군 적용

부산시 구·군 목록 기준 15개 구와 기장군을 포함한 16개 지역을 적용했다.
출처: https://www.busan.go.kr/relationsite 및 https://www.busan.go.kr/15minute/citizen01

대상: 중구, 서구, 동구, 영도구, 부산진구, 동래구, 남구, 북구, 해운대구, 사하구, 금정구, 강서구, 연제구, 수영구, 사상구, 기장군.

- 홈 코스 출발 지역, 탐색 지역 필터, 지도 중심, 상점/서비스/관광 콘텐츠 등록 지역 선택에서 전체 구·군 사용.
- 탐색 화면과 홈에 접을 수 있는 16개 구·군 디렉터리 제공. 이름과 주요 동네 키워드 표시.
- 한국어/영어/일본어/중국어 지역명 제공. 검색은 구·군 이름과 주요 동네 키워드를 함께 조회.
- 기존 `gwangalli`는 수영구, `seomyeon`은 부산진구로 표시. 저장된 코스/업체/스탬프와의 호환을 위해 기존 내부 ID를 유지하며 `districtId`에 행정구 ID를 기록.
- 해운대·광안리·서면·영도 기존 샘플 장소 16개 유지. 나머지 구·군에 검증되지 않은 업체나 운영 정보를 임의 생성하지 않음. 업체 등록·승인 후 해당 구·군에 노출.
- 장소가 없는 구·군은 콘텐츠 등록 준비 안내. 검증된 장소가 없는 상태에서 코스나 스탬프를 만들어 내지 않음.
- 지도 좌표는 대표 지점의 대략적인 값으로, 구·군 경계 데이터가 아님. GPS 지역 제안은 대표 지점과의 거리 기반이며 행정 경계 판정이 아님.
- 완주 보상 캠페인 `busan-four-areas-v1`은 기존 4개 지역을 유지. 16개 전체 완주로 자동 변경하지 않음. 추가 구·군별 스탬프 캠페인은 운영 정책 확정 후 별도 도입.
