# NOWRO 검수와 남은 제작 순서 — 2026-10-18

사용자 요청에 따라 APK/AAB 설치 및 Google Play 등록은 기능·운영 검수 이후로 둔다. 이번 작업에서 유료 서버·외부 배포·앱 등록을 실행하지 않았다.

## 이번 검수에서 수정한 내용

업체 온보딩 기능을 추가했다. 일반 회원은 설정 화면에서 업체를 신청하고, 관리자는 소유권 확인 방법·확인 여부·심사 메모를 남겨 승인 또는 반려한다. 승인된 업체만 전문가 권한을 받고 자기 업체명과 지역으로 상품을 등록할 수 있다. 권한 회수 시 게시 대기·게시 상품은 다시 공개되지 않으며, 재승인도 자동 재게시하지 않는다. 업체 연락처는 관리자 화면과 감사 기록에만 남고 공개 목록에는 노출하지 않는다.

| 발견 사항 | 수정 결과 |
|---|---|
| 메일 링크 로그인인데 인증번호 입력을 필수로 표시 | 링크 안내를 기본으로 표시하고, 메일에 번호가 있는 경우만 선택 입력. 재요청 대기시간과 이메일 변경 제공 |
| 회원에게도 계정 동기화 미연결·7일 삭제 안내 | 5개 언어로 회원/비회원 저장 안내를 구분하고 저장 완료 알림을 분리 |
| 계정이 바뀌었는데 이전 보상 조회 결과가 남을 수 있음 | 계정에 따라 보상 화면을 새로 생성. 회원 데이터와 동의를 모두 조회한 후 화면 상태를 함께 갱신. 조회 실패 시 이전 개인 기록 비우기 |
| 인증은 성공했지만 기록 조회 실패를 링크 오류로 표시 | 로그인 성공과 기록 조회 상태를 분리. 인증 링크를 다시 소비하지 않고 계정 기록만 재조회 |
| 보상 신청 성공 후 목록 조회 실패 시 신청 폼 재표시 | 접수 완료 상태를 유지하고 조회 재시도 제공. 배송 입력값 전체 초기화 |
| 회원 배송 정보도 7일 후 삭제된다고 안내 | 실제 회원/비회원 보관 방식에 맞게 동의 문구 수정. 정식 보관·삭제 정책 미확정 사실 명시 |
| 로그인 확인창의 키보드 포커스 및 뒤로가기 처리 누락 | 공통 모달로 통합하고 최상위 창에만 포커스 순환·Escape·뒤로가기 적용 |
| 위치가 계산에만 쓰인다고 안내하지만 저장 코스에 포함 가능 | 저장 코스에 출발·복귀 위치와 여행 조건이 포함될 수 있음을 안내 |

빌드와 자동 테스트 54개 통과. 메모리 DB와 가상 인증 제공자를 사용하는 격리 브라우저 시험에서 업체 신청, 관리자 승인 요건, 전문가 스튜디오 자동 연결, 기존 여행자 화면과의 이중 사용, 등록 정보 고정, 권한 회수 후 게시 차단을 확인했다. 실제 메일 발송이나 실결제 시험을 대신하지 않는다.

## 운영에서 이어갈 검수

기능 흐름은 구현됐지만 실제 운영 관리자 계정과 실제 업체 소유권 증빙을 등록하는 절차가 남아 있다. 로컬 테스트 역할 전환은 운영 가입이 아니다.

1. 운영자가 실제 업체 신청을 확인하고 소유권 증빙을 보관한다.
2. 승인된 계정으로 자기 업체 상품을 등록하고 게시 전 실제 장소 정보를 검수한다.
3. 운영 DB·이미지 저장소로 이관하면서 동일 권한·회수 정책을 유지한다.

## 이후 순서와 완료 기준

| 순서 | 남은 작업 | 완료 기준 |
|---|---|---|
| 1 | 업체 신청·소유권 확인·권한 승인 | 다른 업체 접근 차단, 승인/반려/권한 회수 검증 |
| 2 | 운영 DB와 이미지 저장소 전환 | 기존 자료 백업, 최신 등록·결제·배송 스키마, 권한 정책, 이관 건수 대조 및 복구 확인 |
| 3 | 결제 확인·현장 QR의 운영 연결 | 결제 제공자/매장 검증 방식 확정, 중복·미결제·만료 QR 차단, 취소·환불 시 처리 구현 |
| 4 | 완주 보상·할인·배송 운영 연결 | 4개 지역 완주, 굿즈 또는 할인 중 하나, 재고·배송비·국가 제한·할인 조건 확정 및 중복 지급 차단 |
| 5 | 개인정보와 회원 탈퇴 | 운영 주체·보관 기간·삭제/보존 대상 확정, 계정 삭제와 데이터 처리 구현, 필요한 고지 연결 |
| 6 | 실제 장소·번역·모바일 현장 검수 | 샘플과 실업체 구분, 실제 위치·이동시간 검증, 한국어/영어 사용자 현장 시험 |
| 7 | 고정 HTTPS 서버와 도메인 | 모바일·다른 기기 로그인, 서버 재시작 후 기록 유지, 백업·복구·장애 대응 확인 |
| 8 | Android 패키징과 Google Play | 앞 단계 완료 후 서명·도메인 인증·실기기 설치·내부 테스트·심사 제출 |

회원 로그인은 실제 연결되었지만 운영 기록은 아직 SQLite다. 준비된 초기 Supabase 스키마만으로 최신 운영 데이터 전환이 끝난 것으로 표시하지 않는다. 기존 외부 임시 주소의 현재 동작은 이번 검수 결과에 포함하지 않는다.
