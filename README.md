# NOWRO Korea

**Your Korea. Right Now. / 지금, 진짜 한국으로.**

기획서를 바탕으로 만든 React + TypeScript 모바일 우선 웹앱입니다. 현재 상태는 **실행 가능한 로컬 개발판**입니다. 실제 여행자에게 현장 사용 가능한 서비스로 출시한 상태가 아닙니다.

해외에서 한국을 찾은 여행자와 국내 여행자가 함께 사용하는 서비스입니다. 초기 버전은 외국인 이용을 우선 고려한 영어 기본 화면으로 제공합니다. 브라우저 언어와 관계없이 첫 방문은 영어로 시작하며, 사용자가 선택한 한국어·일본어·중문 설정은 다음 방문에도 유지합니다. 추천에 국적·한국 전화번호·회원가입을 요구하지 않습니다.

## 실행

2026-10-07: Supabase 인증 서버를 연결했고 기본 메일 버튼이 현재 나우로 주소로 돌아오도록 설정했습니다. 메일 링크의 계정 확인→서버 검증→쿠키 로그인 기능을 구현했으며 실제 사용자 로그인 완료 검증은 남아 있습니다. 인증 장애 시 기존 세션을 보존하고, 기록 이관 시 결제 완료 스탬프 증명을 유지합니다. SQLite 백업·검증·새 파일 복구는 [백업 안내](docs/DATABASE_BACKUPS.md)를 확인하세요. 운영 DB 전환·고정 주소 연결은 미완료이며 [계정 및 호스팅 안내](docs/ACCOUNT_AND_HOSTING.md)를 확인하세요. 아래 초기 구현 표는 최신 추가 기능을 모두 반영하지 않은 초기 기록입니다. 최신 지역은 16개 구·군이며 테스트는 46개입니다.

Node.js 24 이상이 필요합니다. 프로젝트 폴더에서 실행합니다.

```powershell
npm ci
npm run dev
```

- 웹앱: http://127.0.0.1:5173
- 로컬 API: http://127.0.0.1:8787
- `npm run dev`는 로컬 운영자 테스트 계정을 활성화합니다. 설정 → Partner / Administrator에서 확인할 수 있습니다.
- 서버 종료 후에도 `.data/nowro.sqlite`에 데이터가 남습니다. 비회원 기록은 7일 후 정리됩니다.

빌드한 앱은 다음으로 확인합니다.

```powershell
npm run build
npm start
```

이때 http://127.0.0.1:8787 로 접속합니다. `npm start`는 운영자 테스트 계정을 기본 비활성화합니다. 샘플 서버는 localhost에만 바인딩할 수 있습니다.

## 구현한 흐름

- NOW: GPS 동의·거부 대체, 수동 권역·좌표, 4개 시간 모드와 직접 시간 조정, 예산·취향·동행자·이동수단·복귀점·마감시간.
- 코스 엔진: 등록된 장소 ID만 사용, 한국 시간의 도착·최종 입장·종료 검사, 이동·체류·대기·복귀·완충 계산, 최대 3개 코스, 장소 교체·제외·순서 변경 후 서버 재계산.
- MAP: 검색·카테고리 필터, 위치·장소·쿠폰 표시 지도, 지도 장애 시 계속 사용할 수 있는 목록, 외부 길찾기, 장소 상세·주소 복사·오류 신고.
- TRIP: 비회원 세션별 코스 저장·조회·삭제. 다른 세션 데이터 차단.
- PASS: 무료 쿠폰 샘플 발급, 수량·1인 1회 제한, 최소 결제금액, 소유 업체 확인, 서버 중복사용 차단, 중지 기능.
- PASSPORT: 현장 QR 및 대체 코드, HMAC 서명·2분 만료·1회용·장소당 1회 검사. GPS를 방문 증거로 사용하지 않습니다.
- Partner / Admin: localhost 전용 테스트 계정, 본인 장소 수정 요청, 쿠폰 확인·중지·집계, 서명 QR 생성, 관리자 승인·반려 및 감사기록.
- EN / KR / JP / 간체 / 번체: 여행자 핵심 흐름. 번역은 출시 전 전문 검수 대상입니다.
- 선택 동의 및 분석 이벤트, PWA manifest·아이콘·서비스워커. API·지도 타일·개인 저장정보는 서비스워커에 캐시하지 않습니다.
- OpenAI Responses API: 서버 전용 선택적 자연어 조건 추출, JSON Schema·출력검사·타임아웃·일 호출 한도·토큰 사용 로그. 미연결·장애 시 입력폼과 규칙형 코스 유지.

| ------------------------------- | ------------------------------------------------------------------------------------ |

| 이동시간                        | 직선거리 기반 우회계수·저속·추가시간으로 보수적 추정. 실제 도로·교통 경로가 아님     |

| Supabase                        | 스키마와 RLS/RPC 준비 파일. 로컬 PostgreSQL 실행 테스트만 수행. 외부 프로젝트 미연결 |
| OpenAI                          | 연동 코드 있음. API 키·모델 미설정, 실제 호출 미검증. 추천 설명은 현재 규칙형 문구   |
| 계정·회원 동기화                | 미구현. 현재 비회원 7일 세션만 제공                                                  |
| 공개 배포                       | 미수행. localhost 개발판만 실행                                                      |

서버 비밀키를 프런트엔드 또는 채팅에 넣지 마세요. 환경변수와 출시 준비는 [운영 문서](docs/OPERATIONS.md)를 참고하세요. 기획서 대비 완료 기준은 [개발 보고서](docs/IMPLEMENTATION_REPORT.md)에 정리했습니다.

## 검증

```powershell
npm test
npm run build
```

단위·서버·PostgreSQL 준비 스키마 테스트를 실행합니다. `tests/postgres.test.mjs`는 PGlite의 PostgreSQL에 Supabase 역할·`auth.uid()`를 모사합니다. 실제 Supabase Auth·REST·Edge Functions 환경 검증을 대체하지 않습니다.

브라우저 검증은 개발 서버 실행 중 Playwright가 있는 환경에서 다음으로 수행합니다.

```powershell
node scripts/ui-check.mjs
```

`PLAYWRIGHT_MODULE`에 기존 Playwright 패키지 경로를 지정할 수도 있습니다. 기본 브라우저는 설치된 Chrome이며 `PLAYWRIGHT_CHANNEL`로 바꿀 수 있습니다. 결과와 화면은 `test-output/`에 저장합니다.

## 구조

```text
src/                 React 화면·다국어·지도
shared/catalog.ts    도시·권역·장소·쿠폰 샘플 (장소 사실은 이곳에서 관리)
shared/engine.ts     위치·운영시간·예산·복귀 제약 계산
server/              API·SQLite·권한·쿠폰·서명 코드·선택적 OpenAI
supabase/schema.sql  다음 단계 Supabase 스키마·RLS·RPC 준비
tests/               코스·권한·HTTP·PostgreSQL 검증
docs/                실행·운영·제약·완료 기준
```

기존 작업 폴더의 다른 프로젝트는 변경하지 않았습니다. 의존성은 고정 버전과 `package-lock.json`으로 관리합니다. Git 변경 범위는 `nowro-korea/`입니다.
